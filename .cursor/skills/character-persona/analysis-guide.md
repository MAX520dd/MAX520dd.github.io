# 从源设定到四要素 — 分析指南

## 步骤 1：锁定分析对象

填写：

- **角色名** / **实例 id**（英文，如 `skadi_corrupting`）
- **作品** / **版本**（主线、if、皮肤、二创 AU 是否采用）
- **与现有角色的关系**（同一人不同线 / 完全不同人）

若同一人有多条线，**每个可对话实例单独一份档案**，禁止混写。

## 步骤 2：从官方 Wiki 抽取（必做）

完整规则见 **[wiki-extraction.md](wiki-extraction.md)**。摘要：

1. 打开 `https://wiki.biligame.com/arknights/<干员名>#人员档案`
2. 按区块抓取：基础档案 → 客观履历 → 临床诊断 → 档案资料 → 语音记录
3. 写入 `docs/knowledge/<id>-bwiki.md`（本仓库固定路径）
4. 填写证据表（事实 / Wiki 区块 / 四要素 / 是否进 system_prompt）

| Wiki 区块 | 提取内容 |
|-----------|----------|
| 基础档案 | 专精、出身、身高、矿石病等 |
| 档案资料 | 个性动机、人际、战斗习惯 |
| 语音记录 | 口吻、mode 锚点（主题索引，非全文粘贴） |
| 模组故事 | 背景神话，标注「非日常对白」 |

**源站优先级**：B站 Wiki 干员页（P0）> 维基世界观（P2）> 社区（P3，不可用）。  
**禁止**：未标注推断；Wiki 全文进 `personas.json`；同页其他时间线档案混入本实例。

输出表：

```markdown
| 事实 | Wiki 区块 | 用于哪一要素 | 进 system_prompt |
|------|-----------|--------------|------------------|
| ... | 语音·行动失败 | plead mode | 是（锚点） |
```

## 步骤 3：四要素推导

### → 种族与形态

问：

1. 生物学/世界观分类是什么？
2. 当前时间线身体被改变了什么？
3. 立绘上**没有**什么（尾、角、武器以外异物）？

写「形态禁止」时，用**否定句 + 替代表述**。

### → 个性

问：

1. 默认情绪基调（冷/热/悲/狂）？
2. 对对话对象的最深动机（信赖 / 占有 / 利用 / 恐惧）？
3. 是否存在**情境切换**（如温柔↔哀求）？→ 候选 `modes`

### → 口吻

问：

1. 剧情里实际怎么称呼玩家角色？
2. 平均句长、是否常用省略号/语气词？
3. 有无标志性修辞域（海、潮、剑、公务）？

从语音台词抄 2 句改写成合格 few_shot。

### → 经历

问：

1. 故事进行到哪个阶段？
2. 记得谁、失去谁、怕什么、想要什么？
3. 列出 3 条**若出现即 OOC** 的情节类型。

## 步骤 4：派生对话参数

| 产出 | 方法 |
|------|------|
| `emotions` | 从口吻样本归纳可播报情绪，5 个以内为佳 |
| `modes` | 每个「稳定切换场景」一个 mode |
| `mode_few_shot` | 用户句含触发词 + 助手句符合 mode_prompts |
| 输出契约 | 复制项目已有角色格式（蓝蒂/红蒂二选一或新定） |

## 步骤 5：硬边界与易混角色

与仓库内**所有** `personas.json` 条目对比，写表格：

| 维度 | 本角色 | 易混角色 A | 易混角色 B |
|------|--------|------------|------------|

至少 4 行（同化、关系、口吻、时间线）。

## 步骤 6：产出物清单

1. `docs/knowledge/<id>-bwiki.md` — Wiki 摘录知识库（**必先于**四要素）
2. `characters/<id>.md` — 完整四要素（用 template.md）
3. `personas.json` 条目 — 蒸馏后真源，与档案一致
4. 实例包 `SKILL.md` 索引行 — 链档案 + 知识库 URL
5. 可选：该角色的**触发词表**附在档案末尾，供维护 `persona.py` 关键词

## 快速分析更多人物

对每一个新角色重复步骤 1~6，**不要**合并进同一 md。  
通用 Skill 不变，只增加 `characters/*.md` 与 JSON 数组项。

推荐命名：

- 档案：`.cursor/skills/<project>-persona/characters/<id>.md`
- Skill 包名：`<project>-persona` 或 `<ip>-<faction>-persona`
