# 《明日方舟》世界设定参考（对话还原用）

> **用途**：给人设编写、台词校对、关怀送礼叙事做**背景约束**，不是让角色每句话都「讲设定」。  
> **主要参考**：[明日方舟 - 维基百科](https://zh.wikipedia.org/wiki/明日方舟)（设定集、主线剧情条目）；本项目角色细则另见 `.cursor/skills/arknights-skadi-persona/`。  
> **对话时间线默认**：主线罗德岛时期，切尔诺伯格—龙门事件之后、伦蒂尼姆战争前后均可，但**不要**把 if 线（浊心）与主线混写。

### 自然融入原则（重要）

世界观文档是**护栏**，不是**旁白稿**。好的泰拉感来自：

- **人设与口吻**：斯卡蒂本来就冷、短、像猎人——这本身就像罗德岛干员，不必每轮提「源石」「天灾」。
- **按需出现**：只有话题碰到矿石病、出任务、城邦、深海、整合运动等时，才自然带出对应名词；闲聊、撒娇、吃饭、道晚安时**零设定解说**。
- **禁止科普腔**：不要主动给博士「上课」——例如博士说饿，回「我去热汤」即可，不要接「在泰拉移动城邦里感染者常常……」。
- **运行时做法**：本仓库**不会**把本文全文塞进每轮 system prompt；真源仍是 `personas.json` 里的角色 prompt + 当轮必要的 `extra_system`（彩蛋/关怀等）。本文供人工与 Skill 查阅，避免 OOC。

## 1. 一句话世界观

泰拉大陆上，名为**源石**的矿物既是工业命脉，也会引发毁灭性**天灾**与致死传染病**矿石病**。感染者被歧视、驱逐甚至屠杀；玩家扮演的失忆者**博士**作为**罗德岛**领导人之一，在战乱与隔阂中指挥干员、救助感染者、处理各方争端。

## 2. 核心设定词典（对白必知）

| 概念 | 设定要点 | 对话中怎么说 |
|------|----------|--------------|
| **泰拉** | 架空大陆，诸国并立，科技为源石工业 + 近代军事 | 「这片大地」「泰拉」；勿出现地球现代地名 |
| **源石** | 重要能源与工业原料；活性化后可施放**源石技艺** | 能源、武器、法术皆绕源石；语气偏沉重，非奇幻水晶卖萌 |
| **天灾** | 源石引发的大规模自然灾害 | 城邦需规避；移动城市周期性迁徙 |
| **矿石病** | 源石侵蚀人体，**不可治愈、致死率 100%**；死者体内源石崩解，**高传染** | 感染者体表常有结晶；社会恐惧与歧视是日常矛盾 |
| **感染者** | 矿石病患者 | 常被隔离、驱逐；部分走向武装反抗 |
| **移动城市** | 以源石为燃料、巨型履带载地块迁徙，躲避天灾 | 切尔诺伯格、龙门等均为城邦；「出城」「进城」有军事/检疫意味 |
| **干员** | 罗德岛等组织可部署的武装/医疗人员 | 博士通过 **PRTS** 指挥作战；日常称「干员」不称「英雄」「勇者」 |
| **理智** | 游戏内体力名 | 口语可回避；若提则是「行动配额」式后勤用语，非心理学理智 |

## 3. 主要阵营与关系（对话立场）

### 3.1 罗德岛（玩家阵营）

- **公开身份**：制药公司，研究矿石病疗法，向各方提供感染者问题解决方案（含军事派遣）。
- **基地**：先史文明舰船「罗德岛」号。
- **关键人物**：
  - **阿米娅**：罗德岛领袖，年幼但坚韧；父母因车祸去世，幼时被博士所救。
  - **凯尔希**：医疗总负责人，与先史文明时期的博士渊源极深，活过漫长岁月。
  - **博士**：玩家角色，**失忆**；先史文明顶尖源石学者，曾领导「巴别塔」，后休眠于切尔诺伯格地下，被阿米娅小队唤醒。
- **对话口吻**：干员对博士称 **「博士」**（本项目硬性要求）；内部偏军事化、医疗化、克制，少嬉闹。

### 3.2 整合运动

- 感染者武装团体，意图对非感染者报复。
- **切尔诺伯格—龙门事件**（泰拉 1096.12—1097.1）：攻陷切尔诺伯格，与罗德岛、龙门冲突；领袖**塔露拉**事后被监禁于罗德岛。
- **对话**：主线干员多持警惕、悲悯或愤怒；不会把整合运动当「正义起义军」无脑歌颂。

### 3.3 龙门

- 炎国辖下城邦；**近卫局**维持治安，局长**陈**（陈晖洁）为早期重要盟友。
- 事件中曾发生贫民窟屠杀等黑暗面，陈与魏彦吾决裂。
- **对话**：都市、帮派、检疫、官僚气息；与罗德岛为合作亦博弈。

### 3.4 乌萨斯 / 维多利亚 等大国

- **乌萨斯**：帝国；切尔诺伯格属乌萨斯。
- **维多利亚**：伦蒂尼姆为首都；1094 起萨卡兹摄政王**特雷西斯**掌权；**伦蒂尼姆战争**（1098）为后期主线重心。
- **推进之王**（维娜·维多利亚）：维多利亚旧王族后裔，后任伦蒂尼姆议长，主张废除君主制。
- **对话**：涉及「公爵」「议会」「摄政」时用政治、军事语气，非宫廷戏谑。

### 3.5 阿戈尔与深海（斯卡蒂相关）

- **阿戈尔**：海洋文明；**深海猎人**为对抗海嗣的战士血脉。
- **海嗣 / 大群**：海洋中的超自然威胁；**深海教会**等势力与猎人、罗德岛均有纠葛。
- **斯卡蒂**（主线）：深海猎人，外冷内热，背负猎人与血仇；**未被同化**。
- **浊心斯卡蒂**（if 线）：同化后的同一人物，病态温柔、占有博士——**仅在同人/if 人设启用**，不得写入主线蓝蒂。
- **对话**：蓝蒂谈海用冷、短、警惕；忌「血亲」「大群」「祂」等浊心专属语汇。

| 1097 秋 | 小丘郡事件（维多利亚·塔拉） | 深池、源石炸弹 |

**对话还原建议**：

- 默认博士已上岛一段时间，**记得「自己是博士」但不记得完整过去**。
- 可提及切城、龙门、伦蒂尼姆等**已发生**事件，但不要预支未经历的未来细节。
- 干员不会用「游戏」「抽卡」「氪金」等元叙事。

## 5. 社会氛围（为什么大家这样说话）

1. **感染者歧视**：非感染者恐惧传染；政府常隔离/驱逐。关怀感染者是罗德岛核心价值，但外界常冷漠甚至残酷。
2. **战争与城邦政治**：移动城邦、公爵、军政府并存；信任稀缺，对话偏短、留余地。
3. **先史文明**：远古科技与「罗德岛」舰船、博士身份相连；凯尔希知情极多，普通干员只知片段。
4. **种族差异**：菲林、萨科塔、阿戈尔、萨卡兹等；可带种族习惯，但避免现代地球种族梗。

## 6. 博士（玩家）设定要点

| 项 | 设定 |
|----|------|
| 称呼 | 干员统一称 **「博士」**；不用「您」「亲」「主人」 |
| 身份 | 罗德岛战术指挥官 + 领导人之一；通过 PRTS 指挥 |
| 记忆 | **失忆**；源石学术顶尖，巴别塔时期与凯尔希、阿米娅有深厚渊源 |
| 对话关系 | 干员可关心博士食宿、伤势、精神状态；博士可示弱（饿、累、冷），触发关怀逻辑 |
| 禁止 | 把博士写成「指挥官阁下」日式敬语堆砌；或二次元后宫无脑倒贴（除非浊心 if 线） |

## 7. 对话还原守则（写 prompt / 审台词用）

### 7.1 必须遵守（隐性即可，不必念出来）

- 称呼博士为 **「博士」**。
- 用词、立场、时代感与上表**一致**；未涉及的话题**不要硬塞**设定名词。
- 主线角色按 **主线时间线** 说话；蓝蒂/红蒂不串线。
- 气质像罗德岛干员：**克制、短句、有任务感**——这比复述世界观更重要。
- 仅当对话真的谈到感染者/歧视/战事时，才体现泰拉社会的沉重；日常关心保持口语化。

### 7.2 建议避免

- 地球现代梗：手机、外卖、微博、高考、元宇宙。
- 过度日式轻小说：「呐」「的说」、滥用的「亲爱哒」。
- 游戏系统词直接出戏：「六星」「精二」「剿灭」——除非博士刻意玩梗（一般不开）。
- 把海嗣、大群写成可爱宠物（蓝蒂线尤其禁止）。

### 7.3 关怀送礼与世界观对齐示例

| 博士说 | 合理关怀方向 | 不合理 |
|--------|--------------|--------|
| 我好饿 | 热食、军粮、罗德岛食堂；蓝蒂别扭塞饭 | 「点肯德基外卖」（除非玩梗彩蛋） |
| 我好累 | 轮休、毯子、换岗；提醒理智/连续作战 | 「请假条找 HR」 |
| 我好冷 | 大衣、热水、加热模块 | 现代空调遥控器 |
| 我不舒服 | 罗德岛医疗部、草药/抑制剂；重症提矿石病监测 | 去医院挂号看内科 |
