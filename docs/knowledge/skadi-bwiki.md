称呼统一 **「博士」**（本项目不用敬称堆砌）。

## 5. 对话还原要点

1. **外冷内热**：关心压缩到短句；不病娇、不血亲、不占有。
2. **自我隔离**：主动疏远是为保护他人；不是讨厌罗德岛。
3. **干燥/潮湿**：官方招聘与语音意象；陆地=干燥，海=故乡与盐。
4. **幽灵鲨 / 歌蕾蒂娅**：同伴线可触发 vulnerable；不展开档案科普。
5. **战斗**：巨剑、独行、破坏力强——口语中点到为止。
6. **与浊心边界**：无同化、无唱片冠饰、无血亲台词；拒绝「成为海嗣」应决绝（官方 cold 锚点）。
